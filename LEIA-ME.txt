MEU PEQUENO MUNDO — PESQUISA YOUTUBE

COMO FUNCIONA
Sem a API, a pesquisa oferece um link para abrir os resultados no YouTube.
Com uma API válida, os resultados aparecem no próprio site, podendo selecionar, reproduzir (quando permitido pelo YouTube) e salvar.

CONFIGURAÇÃO PARA TODOS OS VISITANTES
1. Ative YouTube Data API v3 no Google Cloud.
2. Crie uma chave e restrinja-a à YouTube Data API v3 e ao referer do seu domínio publicado (ex.: https://usuario.github.io/*). Defina cotas.
3. Abra configuracao.js e preencha youtubeApiKey com a chave restrita.
4. Publique index.html e configuracao.js no mesmo diretório.

OPÇÃO MAIS SEGURA
Coloque a chave SECRETA no backend (ex.: Cloudflare Worker, com proteção e limites) e configure youtubeSearchEndpoint no configuracao.js. Esse backend deve responder JSON { items: [{ id, title, channel }], nextPageToken } e permitir CORS do seu domínio.

NOTAS
Configurações de administrador na interface só aparecem com ?admin=1. Esse parâmetro NÃO é autenticação.
Configuração feita por esse painel salva somente no navegador atual. Para todos os visitantes, edite configuracao.js.
A pesquisa exige API; o YouTube não disponibiliza pesquisa oficial arbitrária incorporada sem API.
Filtros não garantem adequação infantil: supervisione os vídeos.

PRIVACIDADE: esta versão não inclui o e-mail pessoal informado no HTML, JS ou arquivos do pacote. O painel técnico de configuração da busca foi ocultado dos visitantes. Para pesquisar DENTRO do site, ainda é obrigatório configurar um endpoint HTTPS ou a chave pública com restrição no arquivo configuracao.js. Sem isso, a pesquisa abre o YouTube em outra aba.
