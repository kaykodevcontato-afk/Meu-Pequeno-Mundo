MEU PEQUENO MUNDO — PLAYER YOUTUBE + PESQUISA

ATUALIZAÇÃO
- YouTube IFrame Player API integrada às áreas de músicas e desenhos.
- Vídeos selecionados reproduzem dentro do site se o YouTube permitir.
- Não há interrupção automática após 6 segundos (isso era somente no exemplo da documentação).
- A sessão de desenhos mantém o limite definido no campo "Tempo por sessão" (10 minutos por padrão).
- Se a API de player não carregar, os controles nativos do vídeo incorporado continuam disponíveis.
- Interface pública não apresenta formulários técnicos de API.

ATIVAR PESQUISA DENTRO DO SITE
1. Entre em https://console.cloud.google.com/apis/library/youtube.googleapis.com e ative YouTube Data API v3.
2. Crie credencial de chave API no Google Cloud; restrinja para seu domínio GitHub Pages e somente essa API. Configure cotas.
3. Edite configuracao.js e preencha youtubeApiKey com a chave de uso no navegador, restrita por domínio e API.
4. Envie index.html e configuracao.js à raiz do repositório GitHub Pages.

ALTERNATIVA MAIS SEGURA
Um endpoint HTTPS próprio configurado em youtubeSearchEndpoint permite manter a chave no servidor (ex.: Cloudflare Worker), com CORS, limites e autenticação adequados.

SEM CHAVE
A pesquisa de vídeos pelo nome no próprio site não é possível sem YouTube Data API v3 ou endpoint equivalente.
Nesse caso, aparece apenas um link para buscar no YouTube e o usuário pode adicionar vídeos pelo link.

OBSERVAÇÕES
A IFrame Player API não realiza pesquisa. Alguns vídeos não permitem incorporação; a filtragem safeSearch não substitui supervisão parental.
Não coloque segredos de backend em configuracao.js: o código do navegador é público.
O pacote não contém o e-mail pessoal mencionado anteriormente.
